# 采集与观测清单

> 本文按层次汇总 AcTrail 可采集和呈现的观测内容。（观测Agent动作均带时间戳信息，此处不重复记录）

| 执行与身份 | 命令活动 | 命令调用、执行进程、完成状态、退出结果 |
| 执行与身份 | Agent 身份 | Agent 类型、身份来源、生命周期、调用关系 |
| 系统活动 | 文件访问 | 文件路径、打开、关闭、访问方式、操作结果、错误 |
| 系统活动 | 文件读写 | 读取次数、写入次数、读取字节数、写入字节数、错误次数 |

| 系统活动 | 管道通信 | 匿名管道、命名管道、通信端点、读写方向、所属进程 |

| 内容与协议 | TLS 明文 | 加密前内容、解密后内容、发送方向、接收方向、所属进程 |
| 内容与协议 | 内容完整性 | 连续字节区间、内容来源、完整状态、截断状态 |
| 内容与协议 | HTTP 请求 | 请求方法、目标地址、路径、请求头、请求正文、内容类型、内容长度 |
