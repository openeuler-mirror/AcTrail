# 前端时间线

Flamegraph（火焰图）与 waterfall（瀑布图）共享连续视口、固定时间原点和窗口缓存。服务端接口见[时间线查询](../../../reference/protocols/web-api.md#时间线)。

| 主题 | 内容 |
|---|---|
| [窗口加载](#窗口加载) | 请求、预取与失效 |
| [窗口缓存](#窗口缓存) | 条目上限、淘汰与展示 |
| [根命令快照](#根命令快照) | 窗口前根命令的合并与裁剪 |
| [总览索引](#总览索引) | 全范围摘要与历史绘图 |
| [LLM 调用编号](#llm-调用编号) | 编号来源、更新与失效 |

## 窗口加载

| 阶段 | 行为 |
|---|---|
| 选择 Trace | 读取 metadata，建立时间范围 |
| 默认类型筛选 | `command.invocation`、`agent.invocation`、`agent.context_compaction`、`llm.call`、`llm.request`、`llm.response`、`http.message` |
| 加载视口 | 先读取可见范围，再预取左右各半屏，保留选中详情 |
| 继续查询 | 按 `next_cursor` 读取后续页，包括带游标的空动作页，达到单窗口上限后停止 |
| 命中缓存 | 完整覆盖时直接复用，部分加载窗口保留已读动作，保留已有窄窗口 |
| 查询失败 | 保留已有数据 |
| 切换 Trace、筛选或显式刷新 | 清空窗口缓存，重新查询 |
| 打开详情 | 按需读取完整动作或 LLM 正文 |

Trace 列表独立按页加载。切换列表页后保持已选中的 Trace。Idle 区间和 time attribution 由用户显式加载。

## 窗口缓存

默认值集中在 [`workspaces/timeline/constants.js`](../../../../crates/apps/web/frontend/src/workspaces/timeline/constants.js)，可通过 `TimelineWindow` 的 options 覆盖。

| 参数 | 默认值 |
|---|---:|
| 初始时间范围 | 30 秒 |
| 导航请求合并延迟 | 120 毫秒 |
| 单窗口查询批数 | 4 |
| 单窗口动作数 | 1000 |
| 单窗口关联端点数 | 1000 |
| 单窗口关联数 | 4000 |
| `maxCachedWindows` | 4 |
| `maxCachedActions` | 4000 |
| `maxCachedContexts` | 4000 |
| `maxCachedLinks` | 16000 |

| 规则 | 行为 |
|---|---|
| 配置约束 | 缓存上限须容纳一次窗口查询 |
| 容量计量 | 按各窗口保存的条目累计，重复条目也计入 |
| 淘汰 | 超过任一上限时，淘汰较久未使用的窗口 |
| 展示 | 按动作身份去重生成展示数据，已加载动作裁剪到当前视窗 |
| 内存组成 | 缓存条目、读取结果及派生绘图模型 |

## 根命令快照

服务端 `root_command_before_window` 补充窗口前最近启动的根命令，每个查询窗口最多保留一个快照。

| 阶段 | 行为 |
|---|---|
| 保存 | 按实际请求的 `from` 和 metadata 中的内部根进程身份关联到窗口 |
| 选择 | 使用覆盖视口左边界的最新查询快照，替换该根进程的窗前命令 |
| 合并 | 按原始 action ID 合并，同 ID 的较新快照更新生命周期 |
| 空快照 | 撤销旧候选 |
| 缓存切换 | 快照变化后重新投影 |
| 绘制 | 已结束与运行中区间按视窗裁剪，结束未知时显示为点 |
| 更新总览 | 将真实结束时间同步到动作摘要与已观测时间范围 |
| 失效 | 随窗口淘汰、筛选变化或 Trace 切换清除 |

命令结束时间取自该动作的原始生命周期。窗口前补读范围为 Trace 根命令的一条前驱快照。

## 总览索引

### 摘要扫描

Trace overview（总览）使用独立索引保存完整筛选范围内的动作摘要。

| 项目 | 行为 |
|---|---|
| 扫描 | 异步顺序翻页，每页 `limit` 取筛选 limit 与 `maxActions` 的较小值 |
| 继续条件 | 按 `next_cursor` 前进，包括空动作页，关联截断后继续动作扫描 |
| 摘要字段 | 原始 action ID、类型、状态和绝对起止时间 |
| 释放 | 每页提取摘要后释放完整响应 |
| 发布 | 扫描完成后统一发布，成功的窗口与实时尾部读取更新已有摘要 |
| 保留 | 详情窗口淘汰后继续保留摘要，内存随动作数量增长 |
| 失败 | 保留已有摘要，提示刷新重试 |
| 清除 | 切换 Trace、筛选或显式刷新时清空，组件销毁时取消扫描 |
| 总览绘图 | 无文本搜索时按类型绘制全部摘要，搜索时按火焰图当前展示模型的匹配结果绘制 |

### 历史动作展示

| 项目 | 行为 |
|---|---|
| 历史泳道 | Agent layer 与 Other observed activity 使用总览索引保留历史动作 |
| 详情驻留 | 按原始 ID 优先使用完整动作 |
| 详情淘汰 | 绘制摘要中的类型、ID、状态与起止时间，点击后加载详情 |
| 分类缓存 | 保留已解析动作的 `layer`、`group`、`modelMessage`、`backgroundKind`，时间与状态每次读取总览索引 |
| 分类缓存失效 | 总览清空、Trace 或索引实例切换时清理，组件销毁时释放 |
| 关系解析 | 未解析关联的摘要按类型分层，subagent 分组和推导时长使用当前驻留关系 |
| 文本搜索 | 摘要匹配类型、ID 和状态，完整名称与目标在详情驻留时参与匹配 |
| 内存范围 | 摘要与派生绘图模型随动作数增长，完整属性、正文和关联受窗口缓存上限约束 |

## LLM 调用编号

| 项目 | 行为 |
|---|---|
| 编号集合 | 完整筛选范围内的全部 `llm.call`，后台调用也保留号位 |
| 排序 | 原始开始时间、action ID |
| 共用范围 | 完整动作与历史摘要使用同一编号表 |
| 首次扫描 | 完整扫描成功前显示无编号调用名，扫描中的新增调用暂不编号 |
| 视口操作 | 平移、缩放、窗口淘汰和关联解析时复用编号 |
| 更新 | overview revision 变化后，在异步模型构建中更新编号表 |
| 清除 | 总览索引清空时清除 |
| 数据变化 | 相同调用集合按相同规则排序，较早调用晚到或开始时间修正时重新排序 |

后台标签使用已解析类型。视口重绘直接复用已有编号表。
