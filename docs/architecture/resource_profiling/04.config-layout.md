# 配置布局

资源观测配置统一位于 resource_profiling；collection、storage、alerts 分别拥有采集、存储和告警子配置。实现状态见 [代码布局](03.code-layout.md)。

| 配置路径 | 填写要求 | 类型 | 配置结构体 | 默认值 | 解释 |
| --- | --- | --- | --- | --- | --- |
| `resource_profiling` | 可省略，使用默认值 | object | `resource_profiling::ResourceProfilingConfig` |  | 资源观测组件配置 |
| `resource_profiling.enabled` | 可省略，使用默认值 | bool |  | `true` | 总开关；关闭时不启动任何资源采集任务 |
| `resource_profiling.collection` | 可省略，使用默认值 | object | `resource_profiling::ResourceCollectionConfig` |  | Host 与 Workload 采集配置 |
| `resource_profiling.collection.host` | 可省略，使用默认值 | object | `resource_profiling::HostProfilingConfig` |  | 独立宿主采集：CPU、内存、负载 |
| `resource_profiling.collection.host.enabled` | 可省略，使用默认值 | bool |  | `true` | 启用宿主采集，不依赖 workload |
| `resource_profiling.collection.host.mode` | 可省略，使用默认值 | enum |  | `linux` | `linux`：真实宿主采集；`noop`：空采样后端 |
| `resource_profiling.collection.host.interval_ms` | 可省略，使用默认值 | uint64 |  | `1000` | 宿主采样周期，毫秒，须大于 0 |
| `resource_profiling.collection.workload` | 可省略，使用默认值 | object | `resource_profiling::WorkloadProfilingConfig` |  | 工作负载采集配置 |
| `resource_profiling.collection.workload.enabled` | 可省略，使用默认值 | bool |  | `true` | 启用工作负载采集，与 host 可同时开启 |
| `resource_profiling.collection.workload.interval_ms` | 可省略，使用默认值 | uint64 |  | `1000` | 工作负载采样周期，毫秒，须大于 0 |
| `resource_profiling.collection.workload.mode` | 可省略，使用默认值 | enum |  | `auto` | `procfs`：使用进程采集；`cgroup`：要求有效 cgroup 绑定；`auto`：优先适用的 cgroup，允许降级时选 procfs；配置错误不降级；`noop`：空采样后端，不解析 procfs/cgroup 子表 |
| `resource_profiling.collection.workload.procfs` | 可省略，使用默认值 | object | `resource_profiling::ProcfsWorkloadProfilingConfig` |  | 仅 `mode=procfs/auto` 时解析；采集进程 CPU、RSS、虚拟内存 |
| `resource_profiling.collection.workload.procfs.include_children` | 可省略，使用默认值 | bool |  | `true` | 包含工作负载后代进程；false 时只采根进程；仅影响 procfs 分支 |
| `resource_profiling.collection.workload.cgroup` | 可省略，使用默认值 | object | `resource_profiling::CgroupProfilingConfig` |  | 仅 `workload.mode=cgroup/auto` 时解析；采集 cgroup 范围的 CPU、内存、I/O 等计数 |
| `resource_profiling.collection.workload.cgroup.mode` | 可省略，使用默认值 | enum |  | `auto` | `auto`：按目标绑定与指标能力优先选 v2，其次 v1；`v1/v2`：固定版本；无可用候选时交外层 workload.mode 处理；配置错误不降级 |
| `resource_profiling.collection.workload.cgroup.v1` | 可省略，使用默认值 | object | `resource_profiling::CgroupV1Config` |  | 仅 `cgroup.mode=v1/auto` 时解析；只读已有 cpuacct/memory 分组，覆盖可能大于 trace |
| `resource_profiling.collection.workload.cgroup.v1.binding_attempts` | 可省略，使用默认值 | uint32 |  | `2` | 绑定时成员路径变化的总尝试次数，须大于 0 |
| `resource_profiling.collection.workload.cgroup.v1.allow_hierarchy_root` | 可省略，使用默认值 | bool |  | `false` | 允许绑定可见 controller 层级根；其计数包含该根范围内全部工作负载 |
| `resource_profiling.collection.workload.cgroup.v2` | 可省略，使用默认值 | object | `resource_profiling::CgroupV2Config` |  | 仅 `cgroup.mode=v2/auto` 时解析；由 v2 委托 managed/external/process_rss 解析 |
| `resource_profiling.collection.workload.cgroup.v2.managed` | 可省略，使用默认值 | object | `resource_profiling::ManagedScopeConfig` |  | v2 自建范围；能力不足交 Factory 选择下一候选，其他创建错误报错；移动 PID 后固定来源 |
| `resource_profiling.collection.workload.cgroup.v2.managed.root` | 可省略，使用默认值 | string |  | `/sys/fs/cgroup/actrail` | 自建范围根路径；须为绝对路径且不能为 `/` |
| `resource_profiling.collection.workload.cgroup.v2.managed.recovery_scan_limit` | 可省略，使用默认值 | uint32 |  | `1024` | 启动恢复扫描数量上限，须大于 0；达到上限报告恢复未完成 |
| `resource_profiling.collection.workload.cgroup.v2.managed.finalization_timeout_ms` | 可省略，使用默认值 | uint64 |  | `30000` | managed 最终采样等待上限，毫秒，须大于 0；超时输出 partial |
| `resource_profiling.collection.workload.cgroup.v2.external` | 可省略，使用默认值 | object | `resource_profiling::ExternalScopeConfig` |  | 已有容器的外部范围接入配置 |
| `resource_profiling.collection.workload.cgroup.v2.external.policy` | 可省略，使用默认值 | enum |  | `disabled` | `disabled`：关闭 v2 外部接入；`prefer`：绑定不可用时交 Factory 选择下一候选；`require`：核验失败则拒绝目标接入 |
| `resource_profiling.collection.workload.cgroup.v2.external.failure_threshold` | 可省略，使用默认值 | uint32 |  | `3` | policy 启用时校验，须大于 0；连续可重试失败达到阈值则绑定失效，成功重置计数；身份不匹配立即失效 |
| `resource_profiling.collection.workload.cgroup.v2.external.binding_attempts` | 可省略，使用默认值 | uint32 |  | `2` | policy 启用时须大于 0；绑定期间成员路径变化时重新核验的总尝试次数 |
| `resource_profiling.collection.workload.cgroup.v2.process_rss` | 可省略，使用默认值 | object | `resource_profiling::CgroupProcessRssConfig` |  | v2 独立管理的进程 RSS 配置 |
| `resource_profiling.collection.workload.cgroup.v2.process_rss.enabled` | 可省略，使用默认值 | bool |  | `false` | 额外采集 v2 绑定范围及后代范围内的进程 RSS |

## 资源存储配置

`resource_profiling.storage` 由 storage 子模块解析。根 Factory 选择 remote、database 或 hybrid；各后端解析自己的子表。Hybrid 向每个子后端 best-effort 分发同一批样本，单个目标失败、超时或队列满时局部记录并继续处理。

| 配置路径 | 填写要求 | 类型 | 配置结构体 | 默认值 | 解释 |
| --- | --- | --- | --- | --- | --- |
| `resource_profiling.storage` | 可省略，使用默认值 | object | `resource_profiling::storage::ResourceStorageConfig` |  | Host 与 Workload 共用的资源存储入口 |
| `resource_profiling.storage.backend` | 可省略，使用默认值 | enum |  | `database` | `remote`：第三方外发；`database`：本地数据库；`hybrid`：多后端 best-effort 分发 |
| `resource_profiling.storage.queue_capacity_batches` | 可省略，使用默认值 | uint32 |  | `64` | remote/database 的后台队列容量，须大于 0；满时丢弃本批；Hybrid 使用自身队列配置 |
| `resource_profiling.storage.remote` | **必填（条件）** | object | `resource_profiling::storage::remote::RemoteResourceStorageConfig` |  | backend=remote 时解析 |
| `resource_profiling.storage.remote.protocol` | **必填（条件）** | enum |  |  | 外发协议：`prometheus_remote_write`、`influxdb_line_protocol` |
| `resource_profiling.storage.remote.endpoint` | **必填（条件）** | string |  |  | 完整 HTTP(S) 写入地址，包含接收端要求的数据库等查询参数 |
| `resource_profiling.storage.remote.headers` | 可省略，使用默认值 | object |  | `{}` | 外发请求头，包括接收端要求的鉴权信息；日志隐藏敏感值 |
| `resource_profiling.storage.remote.timeout_ms` | 可省略，使用默认值 | uint64 |  | `1000` | 单次远端请求超时，毫秒，须大于 0 |
| `resource_profiling.storage.database` | 可省略，使用默认值 | object | `resource_profiling::storage::database::DatabaseStorageConfig` |  | backend=database 时解析 |
| `resource_profiling.storage.database.backend` | 可省略，使用默认值 | enum |  | `sqlite` | 由 DatabaseStorageFactory 选择本地数据库实现 |
| `resource_profiling.storage.database.sqlite` | 可省略，使用默认值 | object | `resource_profiling::storage::database::sqlite::ResourceStorageSqliteConfig` |  | database.backend=sqlite 时解析 |
| `resource_profiling.storage.database.sqlite.path` | 可省略，使用默认值 | string |  | `./actrail-resources.sqlite` | 资源数据库文件，可显式设为主 SQLite 同一路径；相对路径以 operator 配置文件目录为基准 |
| `resource_profiling.storage.database.sqlite.write_timeout_ms` | 可省略，使用默认值 | uint64 |  | `1000` | SQLite 单批写入与锁等待上限，毫秒，须大于 0；Hybrid 可施加更短超时 |
| `resource_profiling.storage.database.sqlite.retention` | 可省略，使用默认值 | object | `resource_profiling::storage::database::sqlite::ResourceRetentionConfig` |  | SQLite 资源样本保留策略 |
| `resource_profiling.storage.database.sqlite.retention.enabled` | 可省略，使用默认值 | bool |  | `true` | 启用过期资源样本清理 |
| `resource_profiling.storage.database.sqlite.retention.max_age_seconds` | 可省略，使用默认值 | uint64 |  | `604800` | 样本保留期限，秒，须大于 0 |
| `resource_profiling.storage.database.sqlite.retention.sweep_interval_seconds` | 可省略，使用默认值 | uint64 |  | `60` | 清理周期，秒，须大于 0 |
| `resource_profiling.storage.database.sqlite.retention.max_samples_per_sweep` | 可省略，使用默认值 | uint32 |  | `4096` | 单轮清理数量上限，须大于 0 |
| `resource_profiling.storage.hybrid` | **必填（条件）** | object | `resource_profiling::storage::hybrid::HybridResourceStorageConfig` |  | backend=hybrid 时解析 |
| `resource_profiling.storage.hybrid.queue_capacity_batches` | 可省略，使用默认值 | uint32 |  | `64` | 每个子后端独立队列的批次数量上限，须大于 0；满时丢弃该目标本批请求 |
| `resource_profiling.storage.hybrid.write_timeout_ms` | 可省略，使用默认值 | uint64 |  | `1000` | 每个子后端单批写入的等待上限，毫秒，须大于 0；超时局部记录 |
| `resource_profiling.storage.hybrid.backends` | **必填（条件）** | object[] |  |  | 非空子后端列表，允许多个同类后端使用不同配置 |
| `resource_profiling.storage.hybrid.backends[]` | **必填（条件）** | object | `resource_profiling::storage::hybrid::HybridChildConfig` |  | 一项子后端描述 |
| `resource_profiling.storage.hybrid.backends[].name` | **必填（条件）** | string |  |  | 本 Hybrid 内唯一的非空名称，用于标识外发目标与局部错误 |
| `resource_profiling.storage.hybrid.backends[].backend` | **必填（条件）** | enum |  |  | `remote` 或 `database`；Hybrid Factory 委托对应 Factory 构造 |
| `resource_profiling.storage.hybrid.backends[].remote` | **必填（条件）** | object | `resource_profiling::storage::remote::RemoteResourceStorageConfig` |  | 子后端为 remote 时解析；字段及要求同 resource_profiling.storage.remote |
| `resource_profiling.storage.hybrid.backends[].database` | 可省略，使用默认值 | object | `resource_profiling::storage::database::DatabaseStorageConfig` |  | 子后端为 database 时解析；字段及要求同 resource_profiling.storage.database |

```toml
[resource_profiling.storage]
backend = "hybrid"

[resource_profiling.storage.hybrid]
queue_capacity_batches = 64
write_timeout_ms = 1000

[[resource_profiling.storage.hybrid.backends]]
name = "local"
backend = "database"
[resource_profiling.storage.hybrid.backends.database]
backend = "sqlite"
[resource_profiling.storage.hybrid.backends.database.sqlite]
path = "./actrail-resources.sqlite"

[[resource_profiling.storage.hybrid.backends]]
name = "metrics"
backend = "remote"
[resource_profiling.storage.hybrid.backends.remote]
protocol = "prometheus_remote_write"
endpoint = "http://127.0.0.1:9090/api/v1/write"
timeout_ms = 1000
```

## 资源告警配置

| 配置路径 | 填写要求 | 类型 | 配置结构体 | 默认值 | 解释 |
| --- | --- | --- | --- | --- | --- |
| `resource_profiling.alerts` | 可省略，使用默认值 | object | `resource_profiling::alerts::ResourceAlertConfig` |  | 工作负载资源告警阈值 |
| `resource_profiling.alerts.cpu_alert_percent_millis` | 可省略，使用默认值 | string |  | `disabled` | 正整数字符串为 CPU 告警阈值；100000 表示一个逻辑 CPU 的 100% |
| `resource_profiling.alerts.memory_alert_rss_kb` | 可省略，使用默认值 | string |  | `disabled` | 正整数字符串为 RSS 阈值；缺失指标标记 unknown |
| `resource_profiling.alerts.memory_alert_current_bytes` | 可省略，使用默认值 | string |  | `disabled` | 正整数字符串为 cgroup charged memory 阈值；阈值不控制采集开关 |
