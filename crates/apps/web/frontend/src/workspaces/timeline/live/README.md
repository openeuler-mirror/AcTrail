# 火焰图自动跟随

火焰图工具栏的刷新按钮默认关闭。开启后图标旋转，串行刷新当前 trace 的尾部时间窗口，自动展开有新动作的层和 Agent 分组，新动作淡入。Resources、Agent 和 Harness 使用同一时间轴，跟随时使用配置的固定展示跨度，默认 30 秒。活动范围不足该跨度时保持起点，超过后平滑右移。每次重新开启跟随都使用配置跨度，Overview 拖选或手动缩放产生的跨度仅用于手动浏览。

动作层和 Resources 的跟随末端由已观测动作的开始、结束时间确定；没有新动作或结束状态更新时停留在最后活动。无结束时间的活动延伸至已观测末端。Trace overview 固定在滚动区域顶部。刷新读到更新的实际开始或结束时间时，概览跟到活动末端，尾部留白为零；后续没有活动推进时，按真实空闲时长逐渐增加留白，默认最多占概览总宽度的 20%。例如实际范围 80 秒时，空闲 20 秒后概览总范围达到 100 秒，之后保持稳定。新活动到来时概览再次跟到实际末端，保留活动之间的真实时间间隔。选区不参与尾部平移动画，概览条形来自覆盖完整筛选范围的轻量动作索引。

关闭按钮、切换 trace 或视图、应用筛选、手动刷新、平移或缩放会停止跟随。浏览器标签页隐藏时暂停请求和时间轴动画，回到前台后继续。读取失败或超时保留已显示的数据，在下一轮重试。系统启用减少动态效果时取消平移、淡入和旋转动画。

## 配置

在构建 actrailweb 前端时通过环境变量或 Vite `.env.local` 设置以下字段。时间字段为正整数，单位为毫秒；留白比例为大于 0、小于 1 的数值。无效值在页面初始化时抛出错误。

| 环境变量 | 默认值 | 用途 |
| --- | ---: | --- |
| `VITE_FLAME_FOLLOW_INTERVAL_MS` | 1000 | 一轮请求完成后到下一轮的间隔 |
| `VITE_FLAME_FOLLOW_MOTION_MS` | 1000 | 时间轴阻尼响应时间，约完成 98% 的位移；新目标延续当前速度 |
| `VITE_FLAME_FOLLOW_ENTRANCE_MS` | 450 | 新动作淡入时长 |
| `VITE_FLAME_FOLLOW_REQUEST_TIMEOUT_MS` | 10000 | 整轮 metadata 和动作查询的超时 |
| `VITE_FLAME_FOLLOW_SCROLL_THRESHOLD_MS` | 30000 | 跟随窗口的固定跨度，活动范围超过该值后开始平移，Resources 与动作层保持对齐 |
| `VITE_FLAME_FOLLOW_SETTLE_MS` | 1 | 位移与响应时间内预计位移均小于此值时结束动画 |
| `VITE_FLAME_FOLLOW_IDLE_TAIL_RATIO` | 0.2 | Overview 空闲留白占总范围的最大比例，0.2 表示最多 20% |

## 数据与开销

`TimelineWindow` 是动作、观测边界和视口的唯一来源。窗口保存已读动作的最新开始时间和观测端点，防止首次跟随沿用普通加载时的墙钟末端，并保持已确认的活动末端不倒退。控制器只持有开关、定时器、当前请求和短暂的动画目标、速度。

`TimelineOverviewIndex` 按原始 action ID 保留类型、状态和绝对起止时间。瀑布图按视口加载有界详情；进入火焰图后，通过现有时间线接口逐页建立完整筛选范围的索引，每页大小取筛选 limit 与 `maxActions` 的较小值。初次扫描完成后切换视图复用已有索引，筛选、切换 trace 和显式刷新重新建立索引。完整响应在提取摘要后释放，扫描不受详情窗口的页数和缓存总量限制；空动作页带有游标时继续，关联截断不影响摘要扫描。扫描完成时统一通知概览绘制，避免每页重新投影全部历史。索引建立后，可视窗口和实时刷新成功时同步更新摘要；实时窗口超过动作读取预算时，索引串行补齐该范围，合并扫描期间新增的待读范围。已结束动作不会被较早的进行中快照重新打开。静默轮询保留概览投影，只有摘要、时间坐标或展示选项变化时重新生成条形。

有界详情投影比较完整 JSON 值，内容相同时复用已发布数组；火焰图模型按内容引用、时间标量、摘要版本、实际编号映射和语言变化调度。空闲轮询复用轨道和布局。已完成历史活动按摘要对象、分类、编号、时间原点和语言复用，运行中活动随观测范围更新；缓存随索引清空和语言切换失效。历史活动缓存随摘要数量增长，实际内容变化时仍重新布局。

概览索引随动作数量增长，每个动作仅保存轻量字段；详情、辅助端点、关联和正文继续遵循各自预算。缓存淘汰和时间原点变化保留摘要；切换 trace、筛选或显式刷新清空摘要，组件销毁取消后台读取。扫描失败保留已取得摘要并提示刷新重试。轻量概览按动作类型分层，LLM 与 Agent invocation 使用 Agent 色，其余使用 Harness 色；消息开关按 request/response 类型过滤。文本搜索时概览沿用当前详情模型的匹配结果。

索引同时维护摘要派生的最晚开始与观测端点，更新记录时增量推进，清空索引时失效。实时观测范围合并这两个端点，保证详情窗口截断或淘汰后仍覆盖全部已知活动；每轮只读取两个时间值，避免遍历历史摘要。观测端点沿用实时窗口的单调推进规则。

每次成功刷新在当前窗口快照中记录实际活动边界是否推进。Overview 在有推进的刷新中使用真实范围；静默刷新中增加从最后活动末端到当前时间的空闲时长，上限为 `实际跨度 × 留白比例 / (1 − 留白比例)`。沿用现有刷新节奏计算；留白仅影响概览展示范围。动作查询、Resources 和动作视口继续使用真实观测边界。当前观测范围被时间筛选裁剪时，概览沿用该范围；关闭跟随恢复实际观测范围。标签页隐藏或读取失败时保留已有展示范围。

metadata 包含当前筛选未展示的动作，末端仅用于确定查询上界。每轮从最后已读活动开始时间向前保留一个展示跨度，读取到 metadata 最新开始时间，再由已读动作的开始、结束时间确定展示范围。跨越空闲区间的查询沿用现有 kind/process 时间索引、分页与候选预算；隐藏活动不会推动展示窗口，旧活动仍能更新结束状态。密集区间仍可能达到读取预算。

成功后把新窗口加入现有有界缓存，保留过渡期间仍可见的旧动作，同 ID 使用较新结果。原点改变时清理旧坐标缓存；本轮数据截断时清理旧覆盖记录，保证截断提示准确；失败保留原画面。动画使用共享 RAF，视口更新后同步画布坐标，只更新坐标，不发网络请求。资源读取合并连续帧的请求，最多一个在途请求，成功后检查最新视口是否仍需读取，避免连续动画让防抖一直等待。接口桶宽或点数上限影响绘图精度时，复用已成功的相同查询，等待范围或精度参数变化后再读取。

完整读取有界窗口可以更新已有动作的结束状态。metadata 的尾部时间表示最后动作的开始时间，不能作为变更标记；界面动作 ID 也不是增量游标。现有接口按动作开始时间筛选，窗口之前开始的长动作可能不在结果内。密集窗口超过现有预算时沿用截断提示，可关闭跟随并缩小窗口查看。完成的 trace 保持刷新，直到关闭开关，以接收延迟落库的数据。

图标转速由 CSS 变量 `--flame-follow-spin-duration` 控制，默认 `1s`。停止发生在过渡期间时，视口落到已经加载的目标窗口，确保所见动作与时间范围一致。
